# KEVIN.md

Python port of `bitgate/totallytics-js` (the reference; its `WIRE.md` is the wire contract). Server: private `bitgate/totallytics`, `src/api-analytics/ingest.ts` (`normalizeBatch`). Never push to either from here.

## Layout
- `src/totallytics/`: `_client.py` (Totallytics, module `flush()`, atexit, fork reset), `_aggregator.py`, `_histogram.py`, `_transport.py` (urllib, retry/413/401/pending cap), `_util.py`, `_runtime.py` (logger `totallytics`, warn_once), `_middleware.py` (shared adapter options/callbacks)
- Adapters: `asgi.py` (generic, lifespan flush, route from `scope["route"]`), `starlette.py`/`fastapi.py` (Request for callbacks), `wsgi.py`, `flask.py` (wraps `app.wsgi_app` + `teardown_request`)
- `tests/fixtures/conformance.json`: generated by `scripts/generate_fixtures.mts` from totallytics-js v0.1.0 (core unchanged through 0.1.1)

## Deliberate choices / gotchas
- `bucket()` uses a pure-Python fdlibm `log` near bucket edges: glibc `math.log` differs from V8 `Math.log` by 1 ulp on ~2% of inputs. Port verified bit-identical to node on 2.74M inputs. Don't "simplify" to math.log.
- `round_ms` = JS `Math.round(x*1000)/1000` (half up); Python `round()` is banker's, never use it for sums.
- `clip` counts UTF-16 units like JS/server. Bodies use `ensure_ascii` JSON (safe with lone surrogates, inflates non-ASCII).
- Diffs vs JS: `flush_interval` in seconds; early flush at `max_batch_rows` (JS: at 10k keys); transport is one thread, sequential (JS concurrent); `describe_error` always `Type: msg` (JS drops the name `Error`); status must be a real int (no string coercion); no SIGTERM hook (would clobber uvicorn/gunicorn), relies on atexit + lifespan.
- FastAPI >= ~0.13x keeps include_router prefixes out of `route.path_format`; full template is private `scope["fastapi"]["effective_route_context"].path_format` (duck-typed). Older FastAPI has it in `path_format`. Both covered by tests (3.9 leg = FastAPI 0.128/Starlette 0.49, others = 0.141/1.7).
- Plain Starlette < 1.0 never sets `scope["route"]`: raw path fallback (server templates it). StaticFiles mounts: raw path.
- Mount path params keep real values (`/m/acme/x/:id`), same as JS express.
- Server now maps param-less 404 routes to `/*` itself.

## Verification recipes
- Conformance regen: `npx tsx scripts/generate_fixtures.mts <totallytics-js checkout at tag> > tests/fixtures/conformance.json` (needs `tsx` only, no npm ci in the JS repo).
- Server check (not in CI, repo is private): clone `bitgate/totallytics`, `npm ci --ignore-scripts`, then `python scripts/server_payloads.py > /tmp/p.json && npx tsx scripts/validate_server.mts <server checkout> /tmp/p.json`. Last run 2026-09-28: 13 batches, 5198 metrics + 205 errors, 0 rejected.
- Prod smoke: batch with key `tt_` + 48 zeros -> 401 `invalid or revoked API key`, no writes.

## Release
- Bump `src/totallytics/_version.py`, push tag `vX.Y.Z` -> `release.yml` builds + publishes via PyPI Trusted Publishing (environment `pypi`).
- PyPI publisher must exist (owner `bitgate`, repo `totallytics-python`, workflow `release.yml`, env `pypi`). v0.1.0 tag was pushed before it existed, so its publish job failed; re-run that job once the publisher is added.
